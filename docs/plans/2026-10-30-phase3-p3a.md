# Phase 3 — P3a Ablation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add the heatmap-target variants needed for the P3a novelty ablation (agnostic / knn3 / mcnn σ rules, divisor, repel shape) and the 6 `p3a_*` configs.

**Architecture:** All variants live in `dccnet/dccnet/datasets/targets.py` behind config keys whose defaults keep current behavior; `torch_dataset.py` passes them through. No model/decode/loss changes.

**Tech Stack:** Python 3.11, numpy, torch, pytest.

**Spec:** `docs/specs/2026-10-30-phase3-design.md` §2

## Global Constraints
- Defaults: `data.heatmap_sigma: radius`, `data.heatmap_divisor: 4`, `data.heatmap_shape: gaussian` → heatmaps bit-identical to commit 42b0203 for every existing config (`d_both`, `d_sigma`, `d_s2`, `b_*`, base).
- σ floor 0.5 cells everywhere; stride s from config.
- Neighbour sets are same-class unless the variant says agnostic.
- `repel`: α = 0.8, support radius r/s cells around each center, value = 1/(1 + α·D′), D′ = d1·(1 + d1/d2)² with d1/d2 = distance (cells) from the evaluated cell to the nearest/second-nearest same-class center (d2 = ∞ if only one), peak exactly 1.0 at each center cell, per-class combine by max.
- Density targets, offsets, radius, masks unchanged by all variants.
- p3a configs: `_base_: base.yaml`, `data.split: splits/synthetic.json`, `model.pretrained: true`, `model.out_stride: 2`, `data.stride: 2`, `model.heads.density: false`, `loss.cc.enabled: false`, `train.epochs_max: 120`, `train.patience: 20`.

## Review Focus
1. Default path bit-identical (regression test against stored arrays from the current implementation).
2. Images with 0, 1 or 2 cells of a class (knn3 / mcnn / repel neighbour fallbacks) — finite, no NaN.
3. Cells after augmentation drop (neighbour stats computed on post-aug circles).
4. Repel map peak = 1.0 exactly at each center cell and < 1 elsewhere; two touching centers produce a valley.
5. Config diff vs `exp_m2_d_both.yaml` only in intended keys.
