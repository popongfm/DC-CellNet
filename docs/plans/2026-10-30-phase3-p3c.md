# Phase 3 — P3c BCCD Overlap Relabel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pre-label the 204-image BCCD overlap set with YOLO26m for Mickie to correct in X-AnyLabeling, import the corrected labels as `splits/bccd_overlap_v2.json`, and evaluate every pooled-trained P3b arm on both the original and v2 labels.

**Architecture:** Inference stays in the existing `yolo_predict.py` (records JSON); `prelabel_bccd.py` is pure merge + export on top of those records, so it is fully testable without Ultralytics. `import_bccd_relabel.py` turns the corrected YOLO txt files back into a split JSON with the SAME image keys as `overlap_bccd.json`, so predictions from any run score against both label sets. Evaluation reuses the P3b runner (`EXP_EXTRA_SPLITS`) and `summarize_loso.py` (`--extra`).

**Tech Stack:** Python 3.11, numpy, PIL, pytest, cmd + bash.

**Spec:** `docs/specs/2026-10-30-phase3-design.md` §4 (and §3 for the arms)

**Base branch:** `dccnet` (see P3b plan).

**Depends on:** P3b plan (`docs/plans/2026-10-30-phase3-p3b.md`) Tasks B4 (`run_exp.*`) and B5 (`summarize_loso.py`) — C3 modifies both. C1/C2 are independent of P3b.

## Global Constraints
- Source split: `<data-root>/splits/overlap_bccd.json` (subset `test`, 204 images, images under `bccd_full/BCCD/JPEGImages/`); never modified.
- Pre-label model: YOLO26m pooled weights (Mickie: `C:\Research\dccnet\runs\detect\runs\yolo26m_pooled\weights\best.pt`), predictions via existing `scripts/baselines/yolo_predict.py --split splits/overlap_bccd.json --subset test --conf 0.001`; prelabel keeps predictions with score ≥ 0.5.
- Merge rule (spec §4.1): drop a GT box whose IoU > 0.7 with an earlier-kept GT box of the same class (GT order as in the split); add a kept prediction iff its IoU with EVERY GT box (any class, after dedupe) is < 0.3; predictions are added in descending score order and also must have IoU < 0.3 with predictions already added.
- Export dir `<data-root>/bccd_relabel/`: `images/<file>` (copies, not links — Windows), `labels/<stem>.txt` (YOLO normalised `cls cx cy w h`, 6 dp, our class order), `classes.txt` = `RBC`, `WBC`, `Platelets` one per line, `review_list.csv`, `prelabel_manifest.json`.
- Relabel rule shown to Mickie in README (spec §4.2): label every RBC whose visible outline is more than half the cell, including cells cut by the image border.
- v2 split: `<data-root>/splits/bccd_overlap_v2.json`, `{"test": [...]}`, same record order and `image` keys as `overlap_bccd.json`.
- Class order everywhere: 0 RBC, 1 WBC, 2 Platelets.

## Review Focus
1. Export refuses to overwrite an existing `bccd_relabel/labels/` (would destroy Mickie's manual corrections) unless `--force`.
2. Import with a missing label file, a class id outside 0–2, or a malformed line → error listing every offending file, nothing written.
3. YOLO normalised ↔ pixel conversion on 640×480 images (non-square) — round trip within 0.01 px of the original box.
4. Image keys of v2 equal those of `overlap_bccd.json`; an evaluation with preds keyed for v1 must score on v2 without key mismatches.
5. Empty label file (image with no cells) is valid and imports as zero boxes.

Prints totals.

**Interfaces:**
- `compare_label_sets(old_boxes, old_labels, new_boxes, new_labels, iou: float = 0.5) -> dict` — greedy same-class matching by IoU descending; returns `{"kept", "added", "removed"}`.
- CLI: `python scripts/import_bccd_relabel.py --data-root data [--relabel-dir bccd_relabel] [--split splits/overlap_bccd.json] [--out splits/bccd_overlap_v2.json] [--progress]`.
